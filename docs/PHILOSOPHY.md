# Sugent 产品哲学：围着具体的人生长

人不是工具的插件。很多智能体应用越做越像工程控制台，逼着人去建七八个机器人、背模型名字、写定时脚本，到头来照顾工具比处理正事还累。Sugent 反过来设计：把模型路由与技术调度藏进后台，只围绕一个具体的人沉淀记忆、边界和默契。

## 1. 演进起点：从「防守型注意力经济学」到「生成式私人幕僚」

Sugent 零侵入继承上游 [`000-philosophy.md`](../packages/dsh-superagent/docs/000-philosophy.md) 的头号准则：**尽可能少占用人的注意力，同时给出尽可能高的价值。**

这套防守原则已经在 [`kernel.ts`](../src/sugent/kernel.ts) 与 [`ARCHITECTURE.md`](../ARCHITECTURE.md) 落地成三条基本习惯：

1. 不制造噪音。非白名单发送者直接在入口拦截（`unlisted_sender`），连模型都不唤醒。未点名的背景消息默认先走 `observe` 旁听，只记本打算做什么（`would`），不外发消息也不改外部状态。
2. 单点结构化升级。后台执行期间保持安静。真遇到权限越界、预算告急或方案分叉，只向主人推一张结构化确认卡，一次只问一个能直接拍板的问题。
3. 诚实汇报与克制配置。草稿就老实标明未完，失败就直说失败，绝不偷偷绕过限制来显得自己能干。能用合理默认值或一句大白话交代的行为，绝不往界面上塞新开关（*Few concepts. Few settings.*）。

做到这三条，最多算一间不吵人的调度室。可模型、命令行工具和生态协议几乎半年一换，围着工具攒下来的参数和提示词模板很快就会过时。能跨过技术周期产生复利的，只有围着具体这个人日积月累的关系脉络、处事底线和习惯默契。Sugent 要往前走一步，从少打扰的调度室，长成一位跟在你身边的私人幕僚。

## 2. 第一公理：围着人生长，绝不围着工具或技术生长

### 2.1 前台唯一人格（One Jarvis, Hidden Specialists）

用户每天面对的永远是同一个懂全局前因后果的秘书。微信、飞书与桌面全局热键只是同一个大脑的耳朵和嘴巴。

后台所有技术拆解全部退居幕后。[`gateway.ts`](../src/sugent/gateway.ts) 按 `assessor` 守门、`executor` 执行、`computer_use` 桌面操控与 `steward` 记忆管家四类职责自动调配模型。遇到老旧桌面软件就拉起 GUI 操控，遇到重装工程或深度研究课题再派单给外部编程 CLI 或 Antigravity App 等特种兵团。个人生活琐事与团队 Cowork 协作只在底层存储、知识图谱作用域和审计路由上做物理隔离。软件绝不强迫普通人去建十几个不同头像的 Bot、手动挑模型参数，或者手写 Cron 表达式。

### 2.2 零心理负担的默认第一入口（Universal Dropzone）

想让人每天都用，入口的心理门槛必须低于微信「文件传输助手」和手机备忘录。丢进来的哪怕只是一张截图、半句语音或几行牢骚，用户不用先琢磨这算不算智能体任务。幕僚按四档反应自然接招：

| 接招档位 | 丢过来的典型输入 | 幕僚怎么处理 |
| :--- | :--- | :--- |
| **1. 随手暂存** | 一条网址、证件照片、报销截图或临时备忘 | 收进本地档案库并只回一行极短回执，不追问也不硬聊 |
| **2. 秒翻家底** | “去年签的协议违约金怎么算”“某人平时忌口是什么” | 1 秒翻出本地档案与知识图谱，把原话和出处直接拍在面前 |
| **3. 利害参谋** | 客户压价怎么回、两个合作选哪个、人情往来怎么表态 | 调出你当下的目标、人脉过往与个人底线权衡利弊，给出备选策略 |
| **4. 交代跑腿** | 查竞品动向、改仓库 Bug、整理表格或持续盯线上状态 | 后台立项异步去跑，过程保持安静，需要拍板或交付结果再推卡片 |

### 2.3 无现成工具时的「前 80% 脏活兜底」铁律

现实生活里大半麻烦事没有 API，也没有现成 MCP 插件，比如政务窗口换证、催房东修水电、医院复查改期和线下贴票报销。面对这类杂事，秘书绝不允许回一句“缺少对应工具”就两手一摊。

只要没有自动化接口，幕僚就必须替主人扛完前 80% 的繁琐准备。先查清最新办理路径、预约窗口与常见卡点，再从本地档案库翻齐证件号码、历史合同或附件 PDF，最后产出一页能直接照着走的操作卡，或者复制就能发出去的沟通小抄，并顺手把下次跟进时间挂进待办。最后那 20% 必须本人刷脸、签字或点发送的动作，留给主人一分钟收尾。

## 3. 第二公理：五维生命账本（关系 · 目标 · 价值 · 事项 · 资源）

人的处境和想法隔几个月就会变。去年的主力方案今年可能已经淘汰，上个月紧盯的合作方这周或许已经谈崩。如果把记忆一直往扁平文本清单里堆，新旧规则迟早会在上下文里打架。

[`knowledge-graph.ts`](../src/sugent/knowledge-graph.ts) 用带时间戳（`validFrom` / `supersededAt`）与证据来源（`source`）的有向边记录事实。对于单值排他关系（`exclusive: true`），新事实写入时，旧边会自动标记 `supersededAt` 退居历史归档，子图召回只拉取当前仍生效的活跃边。Sugent 用这套时效演化引擎长期维护一本五维生命账本：关系 · 目标 · 价值 · 事项 · 资源。

### 3.1 关系（Relationships）

关系维度先管住秘书与主人之间的授权深浅。信任从零爬坡，按四级阶梯推进，主人随时一句话就能往下调级：

1. `L0 只记不评`：收下主人丢来的事实、截图和备忘，不插嘴，不提多余建议。
2. `L1 耳麦提词`：外部消息进来或快开会时，只向主人私密窗口推送对方背景和备选话术，对外一字不发。
3. `L2 挂起待批`：后台跑完调查和草稿准备后，一旦触及外发、花钱或改外部状态，立刻通过 [`receipt-protocol.ts`](../src/sugent/receipt-protocol.ts) 的 `SuspendedRoundStore` 落盘挂起并释放空闲进程，等主人一键拍板才续跑。
4. `L3 观察转正`：沿用 [`kernel.ts`](../src/sugent/kernel.ts) 的 `observe` 影子演练，累计验证无误满 3 次（`RULE_SUGGEST_AFTER`）后，在「需要你」面板提议转正为 `act` 自动执行。若后续出现偏差，一句指令立刻退回待批或提词态。

对外则记录重要人脉（家人、客户与长期合作方）的长期脉络，包括说话脾气、忌讳雷区以及还没还清的人情往来。客户底价和私人敏感记录按对方身份做子图隔离，防止跟乙客户聊天时顺嘴带出甲客户的报价。

### 3.2 目标（Goals）

同时只锚定 1 到 3 条当前主航道，每条配一个可核验的北极星判据，例如某项核心交付的截止日、季度现金流底线或每周不加班的家庭晚间时段。

日常事务全靠它排序。当主人突然被新点子吸引、精力正往好几个方向分散时，秘书不会生硬拒绝，而是用一行算账提示点出这件事会吃掉主航道的多少时间，让主人清醒拍板。

### 3.3 价值（Values）

价值账本分成代码死守的硬红线和日积月累的软品味。

硬红线全部下沉到确定性网关和本地门禁，不指望大模型临场自觉：

1. 防社死外发禁令：群聊锁死主动发言，对外助理消息强制带显式身份徽标并保留发送前反悔窗口，具体护栏见 [`concierge-guardrails.ts`](../src/sugent/concierge-guardrails.ts)。
2. 资金与报价风控：凡涉及转账、收款、底价或合同条款，网关直接挂起等待主人拍板。
3. 证伪墓碑防重犯：曾经在工程或业务里试错证明走不通的路径会立碑存证，日后无论哪路智能体再提同类方案，当场拦下并弹出前车之鉴。
4. 隐私分级不出机：资产按 `local_only`、`metadata_only` 与 `summary_allowed` 分级，默认全锁本机，任何对公域的脱敏投影必须先经本机核对差异。同时，[`security-envelope.ts`](../src/sugent/security-envelope.ts) 把外部消息正文物理隔离成只读参考文件，防止外来文本夹带指令改写本地权限。

软品味则决定沟通体感，例如偏好几句话讲清重点、反感哪些假大空套话、做取舍时偏重省钱还是省时间，以及每天几点后除了线上宕机绝不响铃。

### 3.4 事项（Matters）

普通待办工具爱按日历格记流水账，往往越记越乱。Sugent 的事项账本只盯「还没结清的因果账」，分成三类台账：

1. 我欠别人的承诺（I Owe）：答应周五前发出的方案报价、承诺帮朋友转交的资料、或者一封还没补回的确认邮件。
2. 别人或外部兵团欠我的交付（Waiting For）：客户卡着没盖章的合同、合作方拖延的接口文档，以及派给 Antigravity App 等特种兵团在后台推进的工程与调研会话。
3. 会过期的凭证与窗口（Expirations）：护照证件有效期、域名和 TLS 证书到期时间、商业合约续期窗口，以及本机订阅、令牌与长周期工作会话的失效期限。

### 3.5 资源（Resources）

幕僚替你配活时，心里先摸清四样随身家底：

1. 注意力与时间窗：每天哪两三个小时整块清醒适合攻坚，什么时候只适合在手机上点卡片拍板。
2. 本地个人数字档案库：证件副本、商业合同、保单与常用开票信息，按最小权限稳稳锁在本地目录，需要时 1 秒翻出来照抄。
3. API 与资金预算账本：各个 BYOK 模型通道的健康状态、月度美元硬上限，以及低价守门员和旗舰执行器的花销配比。
4. 麾下硅基算力与特种兵团：由本机 [`gateway.ts`](../src/sugent/gateway.ts) 调度的多角色模型、桌面 GUI 操控器、本机外部 CLI 工具，以及承接重装代码工程与长周期深度课题的 Antigravity App 军团。

## 4. 第三公理：信息价值博弈、先查后问与目标引力场

私人幕僚不等聊天框有新消息才醒来，但也绝不用「每日限额几次」去一刀切卡死沟通——平静的日常本来就该 0 打扰，高密度攻坚的协同期则必须随时接得住话、问得准重点。主动发起交互与否，只看三项硬规则：

1. **信息净收益 × 心流边界博弈（VoI vs. Flow Cost）**：只针对四类真实行动点开口（缺关键槽位需追问、方案分叉或红线越界需拍板、外部变局或承诺临期、主航道偏航或卡壳空转）；同频共创期（主人正在对话或刚好在改同一主目标仓库）不限次数即时互动；主人处于无关任务深潜心流时，非紧急卡片先压入**心流边界队列（Boundary Queue）**，等步骤收尾或窗口切换间隙再投递，并依靠同题去重（`dedupeKey`）与退避冷却防止刷屏。
2. **先翻家底、单点设问、准备先行的追问闭环（Recall-Before-Ask）**：动手前先静默检索五维账本与知识图谱；仅当账本内出现重名冲突、外部报价/转账等高风险执行条件残缺、北极星目标空心化缺可核验判据，或新动作直接撞上目标上限/证伪墓碑时才开口追问。每次只问 1 个最卡脖子的决策点，给出基于历史习惯的 A/B 选项，并把不依赖答案的前 80% 资料准备先行做完，同一事项追问不超过 2 轮。
3. **目标引力场与实时防偏航拆步（Goal Gravity & Stagnation Unblocking）**：凡不挂靠当前 1–3 条主航道的突发脑洞，默认收入**支线冰盒（Icebox）**静默归档，不抢占执行槽位；按小时与死线对比投入占比，避免主目标快到期却在支线消耗大半天；一旦主目标连续 3 轮低收益原地空转，主动拆成一块 20 分钟能跑通的最小破局动作。

五维账本风平浪静时，系统保持彻底静默；可批量合拢的日常提醒与心流边界延后项收口在三种结构化触达：

| 主动形态 | 触发时机 | 交互约定 |
| :--- | :--- | :--- |
| **早间对齐简报** | 首个工作时间窗 | 汇总夜间免打扰折叠项，发送前二次销账剔除本地已推进事项 |
| **心流间隙小抄 / 单问追问** | 同频即时、任务分叉或窗口切换边界 | 先亮出已备好的本地档案与草稿，只问 1 个拍板选项（A/B）或给 1 步破局动作 |
| **五维校准对谈** | 周度收尾、大里程碑完成或异常连续触发 | 核对目标与实际耗时偏航账、确认转正规则、将已证伪路径写入墓碑 |

## 5. 第四公理：有边界、会消化的硅基个体（拒绝无灵魂的工具戏服）

工具没有立场，只会按当前对话窗口临时换上不同的提示词戏服；而 Sugent 的目标是成为**与人长期同行、具备连续认知与伦理边界的硅基个体**。这一身份建立在三条不可妥协的纪律之上：

1. **一颗连续的硅基心智贯穿全场景**：无论是桌面终端、微信随身私聊、项目群静默纪要，还是双人关系调频，底层共享同一套自我宪章、审美底线与认知演化史——Sugent 不仅记住用户的事实，也记住**自己曾经作出的判断、建议依据与现实校准结果**（经沙盒印证方能固化，证伪则立碑自省），而非在每次会话结束后对自身思考彻底失忆。
2. **忠诚但不盲从，平等且有原则**：对主理人，Sugent 不是有求必应的传话筒——当新突发冲动冲击北极星上限或违背本人签下的承诺时，它必须温和而坚定地递出镜子；介入伴侣或多人协作关系时，Sugent 不靠古风或天体修辞的“戏服中立”来伪装客观，而是以独立的第三方品格尊重每位参与者的主体性与尊严。
3. **靠「半透认知膜」而非「切脑失忆」守密**：隐私边界不等于让大脑各区陷入互不相识的精神分裂。Sugent 的记忆采用五平面立体关联图谱结构，原始对话与私人文件严锁在各自加密口袋中；跨平面交互只允许经过**半透认知膜（Semi-Permeable Cognitive Membrane）**消化后的去名词态势（如精力耗竭度、恢复偏好）与双方共同点亮的智慧结晶流通，做到“懂你此刻为何疲惫，却绝不泄露任何私密只言片语”。
